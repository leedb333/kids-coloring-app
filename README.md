# 알록달록 색칠놀이터

4~7세 어린이를 위한 한국어 색칠 웹앱입니다. 삼성 갤럭시탭 가로 화면을 중심으로 만들었으며, 휴대폰 세로 화면에도 대응합니다. HTML·CSS·JavaScript와 직접 제작한 SVG만 사용합니다. 앱 실행에 별도 빌드나 외부 라이브러리가 필요하지 않습니다.

## 사용 순서

1. 첫 화면에서 토끼·공룡·고양이·자동차·꽃 중 하나를 누릅니다.
2. 오른쪽 색칠 종이 옆에서 원하는 색을 누릅니다.
3. **색 채우기**를 누른 뒤 그림의 안쪽을 톡 누릅니다.
4. 직접 그리려면 **자유 그리기**를 누르고 종이에 손가락을 움직입니다. **붓 크기**로 굵기를 바꿉니다.
5. **되돌리기**는 마지막 작업을 취소합니다. 최근 60개 작업까지 가능합니다.
6. **처음부터 → 새로 시작**을 누르면 현재 그림만 하얗게 됩니다. 초기화도 되돌릴 수 있습니다.
7. **그림 저장**을 누르면 흰 배경의 PNG 파일이 다운로드됩니다. 갤럭시탭의 **내 파일 → 다운로드**에서 확인하세요. 자동으로 사진첩에 들어가는지는 브라우저와 기기 설정에 따라 다릅니다.
8. **그림 고르기**로 첫 화면으로 돌아갑니다. 그림마다 색칠한 내용은 기기에 자동 보관됩니다. 브라우저 데이터 삭제 시 없어집니다. 되돌리기 기록은 앱을 새로 열면 없어집니다.

## Pull Request 반영하기

1. 전달받은 Pull Request 링크를 누르고 GitHub에 로그인합니다.
2. **Files changed**를 누르면 추가한 파일을 볼 수 있습니다.
3. **Conversation**으로 돌아갑니다.
4. 아래쪽 **Merge pull request → Confirm merge**를 누릅니다.
5. 권한이나 보호 규칙 때문에 버튼이 안 보이면 저장소 관리자에게 병합을 부탁하세요.

## GitHub Pages 배포하기

1. 저장소 상단 **Settings**를 누릅니다.
2. 왼쪽 **Pages**를 누릅니다.
3. **Build and deployment → Source**에서 **Deploy from a branch**를 고릅니다.
4. **Branch**에서 **main**, 폴더에서 **/ (root)**를 고르고 **Save**를 누릅니다.
5. 잠시 뒤 **Actions**에서 `pages build and deployment`가 초록색으로 완료되는지 확인합니다.
6. **Settings → Pages → Visit site**를 누릅니다.
7. 이 저장소의 예상 주소는 `https://leedb333.github.io/kids-coloring-app/`입니다. 배포 성공 전에는 열리지 않을 수 있습니다.

공개 Pages 제공 여부는 저장소 공개 여부와 GitHub 요금제에 따라 달라집니다. Pages 사용이 제한되어 있으면 GitHub가 표시하는 안내를 확인하세요.

## 갤럭시탭 설치·오프라인 사용

1. 갤럭시탭 Chrome 또는 Samsung Internet에서 배포된 HTTPS 주소를 엽니다.
2. 첫 화면의 그림 5개가 표시될 때까지 기다립니다. 처음에는 인터넷이 필요합니다.
3. 앱 안에 **＋ 앱 설치**가 보이면 누릅니다. 안 보이면 브라우저 **⋮ 메뉴 → 앱 설치 / 홈 화면에 추가**를 누릅니다. 메뉴 이름은 브라우저마다 다릅니다.
4. 홈 화면 아이콘으로 다시 열어봅니다.
5. 비행기 모드에서 다시 실행해 오프라인 사용을 확인합니다. 캐시가 브라우저에서 삭제되면 인터넷 연결 후 다시 열어야 합니다.

PWA는 가로 방향을 요청하지만 기기·브라우저에 따라 강제되지 않을 수 있습니다. 탭을 가로로 돌려 사용하세요.

## 주요 파일

- `index.html`: 그림 선택과 색칠 화면, 초기화 확인창
- `styles.css`: 파스텔 디자인, 큰 버튼, 화면 크기 대응
- `app.js`: 영역 색칠, 포인터 그리기, 60단계 되돌리기, 기기 보관, PNG 저장
- `assets/*.svg`: 직접 만든 5개 그림과 앱 아이콘
- `manifest.webmanifest`: 설치 이름·아이콘·가로 방향 설정
- `sw.js`: 앱과 5개 그림을 캐시에 보관하여 오프라인 실행
- `.nojekyll`: GitHub Pages 정적 파일 제공 설정
- `tests/browser.cjs`, `TEST_RESULTS.md`: 기능 검증 코드와 결과

## 개인정보

로그인·광고·결제·분석 도구·외부 폰트·외부 라이브러리가 없습니다. 그림은 브라우저의 로컬 저장소와 사용자가 다운로드하는 PNG에만 저장합니다. 그림 및 개인정보를 외부 서버로 전송하는 앱 코드는 없습니다. 첫 접속과 앱 파일 다운로드에는 호스팅 서버에 대한 일반적인 웹 요청이 발생합니다.

## 개발자용 로컬 실행·테스트

파일을 직접 더블클릭하는 방식 대신 HTTP 서버를 사용하세요. 서비스 워커는 HTTPS 또는 localhost에서만 동작합니다.

```sh
python -m http.server 8765 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8765`를 엽니다. 앱 자체는 패키지 설치가 필요 없습니다. 자동 테스트를 실행하는 개발자만 Playwright와 sharp, Chromium이 필요합니다.

```sh
npm install --no-save playwright sharp
node --check app.js
node --check sw.js
node tests/browser.cjs
```

환경별로 `CHROMIUM_PATH`, `TEST_URL`, `TEST_OUTPUT`을 지정할 수 있습니다. 테스트 브라우저 기본 경로는 `/usr/bin/chromium`입니다. 테스트는 localhost의 전용 브라우저에만 데이터를 기록합니다.

앱 업데이트 시 `sw.js`의 `CACHE` 버전을 올리세요. 새 서비스 워커가 활성화되면 페이지를 다시 열어 업데이트된 파일을 사용합니다.
